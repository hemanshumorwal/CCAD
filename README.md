# 💳 Credit Card Analytics Dashboard | Power BI

An interactive **Credit Card Analytics Dashboard** developed using **Power BI** to analyze credit card transactions, customer behavior, and revenue performance. This project transforms raw financial data into actionable business insights, enabling organizations to understand customer spending patterns, identify high-value customer segments, and support data-driven business decisions.

---

# 📌 Project Overview

Credit card transaction data provides valuable insights into customer behavior, spending habits, and business performance. This project focuses on analyzing transaction trends, customer demographics, and revenue distribution through interactive Power BI dashboards.

The report is divided into two dashboards:

- **Credit Card Transaction Report**
- **Credit Card Customer Report**

Together, these dashboards help businesses monitor financial performance, understand customer segments, and optimize decision-making.

# 📈 Dashboard Analysis

## 💳 Credit Card Transaction Report

This dashboard focuses on overall transaction performance and financial metrics.

### Features

- Revenue Analysis
- Transaction Volume Analysis
- Interest Earned Tracking
- Card Category Performance
- Expenditure Type Analysis
- Transaction Mode Analysis (Swipe, Chip, Online)
- Quarterly Revenue Trends
- Interactive Filters & Slicers

### Key Insights

- Swipe transactions generated the highest revenue.
- Q2 and Q3 recorded higher transaction activity.
- Blue Card category contributed the highest revenue.
- Bills, Entertainment, and Fuel were the top expenditure categories.

---

## 👥 Credit Card Customer Report

This dashboard analyzes customer demographics and purchasing behavior.

### Features

- Customer Segmentation
- Revenue by Income Group
- Revenue by Education Level
- Occupation-wise Revenue Analysis
- Age Group Analysis
- Marital Status Analysis
- Weekly Revenue Trends
- State-wise Revenue Distribution

### Key Insights

- High-income customers generated the highest revenue.
- Businessmen and White-collar professionals were the most valuable customer groups.
- Customers aged **30–50 years** contributed the highest revenue.
- Married customers spent more than single customers.
- A few states accounted for a significant share of overall revenue.

---

# 💡 Business Insights

- Blue Card holders are the highest revenue contributors.
- Customer income strongly influences spending behavior.
- Transaction mode preferences directly impact revenue generation.
- Customer segmentation helps identify high-value customers for targeted marketing.
- Geographic revenue analysis enables region-specific business strategies.
